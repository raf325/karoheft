# Karoheft

Mitschreib-App für Mathe-Vorlesungen: mit dem Stift auf Karopapier schreiben, Definitionen und Sätze markieren, Aussagen und Beweise von Wikipedia oder Gemini ergänzen lassen, als PDF speichern.

**App öffnen:** https://raf325.github.io/karoheft/

Auf dem iPad in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Auf Android in Chrome → ⋮ → „App installieren“.

Die Notizen bleiben auf deinem Gerät. Sicherungen speicherst du über ⋯ → „Alle Hefte sichern“.
